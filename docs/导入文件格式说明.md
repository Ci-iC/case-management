# 案件台账导入文件格式说明

## 基本要求

- 文件后缀：`.txt`
- 内容格式：JSON
- 编码：UTF-8

---

## 顶层结构

```json
{
  "exportVersion": "1.0",
  "exportDate": "2026-04-16",
  "caseCount": 1,
  "cases": [ ... ]
}
```

| 字段 | 说明 |
|---|---|
| `exportVersion` | 固定填 `"1.0"` |
| `exportDate` | 文件生成日期，格式 `YYYY-MM-DD` |
| `caseCount` | cases 数组的长度 |
| `cases` | 案件对象数组 |

---

## cases 数组字段

### 必填字段

| 字段名 | 类型 | 说明 |
|---|---|---|
| `id` | string | 唯一 ID，可用时间戳+随机串，如 `"1713206400123-abc1"` |
| `caseNumber` | string | 案件编号，如 `"SH2026-001"`（追加导入时用于去重） |
| `caseName` | string | 案件名称 |
| `causeOfAction` | string | 案由，如 `"建设工程施工合同纠纷"` |
| `disputeType` | enum | 争议类型，见下方枚举 |
| `court` | string | 受理法院 / 仲裁机构 / 监管机关 |
| `stage` | enum | 案件阶段，见下方枚举 |
| `assignedLawyer` | string | 承办律师 |
| `businessDepartment` | string | 对接业务部门 |
| `ourParty` | string | 我方主体 |
| `opposingParty` | string | 对方主体 |
| `currentProgress` | string | 当前进展描述 |
| `createdAt` | string | 创建时间，ISO 8601 格式，如 `"2026-04-16T09:00:00Z"` |
| `updatedAt` | string | 更新时间，ISO 8601 格式 |
| `createdBy` | string | 固定填 `"current_user"` |
| `isArchived` | boolean | 固定填 `false` |

### 可选字段

| 字段名 | 类型 | 说明 |
|---|---|---|
| `judgmentDocumentNumber` | string | 裁判文书编号 |
| `closingMethod` | enum | 结案方式，见下方枚举（结案/执行阶段建议填写） |
| `thirdParties` | string | 第三人 / 关联方 |
| `opposingLawyer` | string | 对方代理人 |
| `opposingFirm` | string | 对方律所 |
| `totalAmount` | number | 涉案金额（单位：万元） |
| `ourClaimAmount` | number | 我方主张金额（万元） |
| `opposingClaimAmount` | number | 对方主张金额（万元） |
| `filingDate` | string | 立案日期，格式 `YYYY-MM-DD` |
| `arbitrationHearingDate` | string | 仲裁开庭时间 |
| `firstTrialHearingDate` | string | 一审开庭时间 |
| `secondTrialHearingDate` | string | 二审开庭时间 |
| `hearingDate` | string | 开庭日期（通用） |
| `judgmentDate` | string | 判决 / 裁决日期 |
| `nextKeyDate` | string | 下一关键节点日期，格式 `YYYY-MM-DD` |
| `nextKeyDateLabel` | string | 下一关键节点说明 |
| `mainDisputes` | string | 主要争议焦点 |
| `ourPosition` | string | 我方诉求 / 抗辩要点 |
| `judgmentResult` | string | 判决结果 |
| `executionProgress` | string | 回款 / 执行进展 |
| `reviewNotes` | string | 复盘要点 |
| `remarks` | string | 备注 |

---

## 枚举值（必须使用英文 key）

### disputeType 争议类型

| 值 | 含义 |
|---|---|
| `contract` | 合同纠纷 |
| `labor` | 劳动争议 |
| `ip` | 知识产权 |
| `tort` | 侵权 |
| `compliance` | 合规 / 行政 |
| `other` | 其他 |

### stage 案件阶段

| 值 | 含义 |
|---|---|
| `filed` | 立案 |
| `hearing` | 审理中 |
| `first_trial` | 一审 |
| `second_trial` | 二审 |
| `execution` | 执行 |
| `closed` | 结案 |

### closingMethod 结案方式

| 值 | 含义 |
|---|---|
| `withdrawal` | 撤诉 |
| `settlement` | 和解 |
| `judgment` | 判决 |

```json
{
  "exportVersion": "1.0",
  "exportDate": "2026-04-16",
  "caseCount": 1,
  "cases": [
    {
      "id": "1713206400123-abc1",
      "caseNumber": "SH2026-001",
      "caseName": "某公司建设工程施工合同纠纷案",
      "causeOfAction": "建设工程施工合同纠纷",
      "disputeType": "contract",
      "court": "上海市第一中级人民法院",
      "stage": "first_trial",
      "assignedLawyer": "张律师",
      "businessDepartment": "工程事业部",
      "ourParty": "星辰科技集团有限公司",
      "opposingParty": "某建筑有限公司",
      "currentProgress": "已完成庭审，等待判决",
      "totalAmount": 3200,
      "ourClaimAmount": 3200,
      "filingDate": "2026-01-15",
      "firstTrialHearingDate": "2026-03-10",
      "nextKeyDate": "2026-05-15",
      "nextKeyDateLabel": "一审宣判",
      "mainDisputes": "工程款金额认定及违约责任归属",
      "ourPosition": "要求对方支付剩余工程款3200万元及违约金",
      "createdAt": "2026-01-15T09:00:00Z",
      "updatedAt": "2026-04-16T09:00:00Z",
      "createdBy": "current_user",
      "isArchived": false
    }
  ]
}
```

## 导入模式说明

系统支持三种导入模式，在导入界面选择：

| 模式 | 说明 |
|---|---|
| 追加新案件 | 仅导入 `caseNumber` 不重复的案件，重复的跳过 |
| 覆盖编号后全部导入 | 忽略原案件编号，自动改为"暂时01、暂时02..."后全部导入 |
| 覆盖全部数据 | 删除现有所有案件后替换，**不可撤销** |
