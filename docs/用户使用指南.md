## 1. 快速启动

### 环境要求

- Node.js 18 或以上版本
- npm 9 或以上版本（随 Node.js 一同安装）

### 启动步骤

打开 **命令提示符（cmd）** 或 **PowerShell**，执行以下命令：

```
cd C:\Users\GXT08\case-management
npm install        （首次运行需要，后续无需重复）
npm run dev
```

启动成功后，打开浏览器访问：

```
http://localhost:5173
```

### 停止服务

在命令行窗口按 `Ctrl + C` 即可停止。


### 统计卡片说明

| 卡片 | 含义 |
|------|------|
| **全部案件** | 系统中未归档的案件总数 |

## 3. 案件列表

### 表格列说明

| 列名 | 说明 |
|------|------|
| **案件编号** | 唯一标识，格式示例：SH2026-001 |
| **案件名称** | 完整案件名称，下方灰色文字为案由 |
| **争议类型** | 彩色标签，见第 10 节颜色说明 |
| **案件阶段** | 彩色标签，见第 10 节颜色说明 |
| **我方主体** | 己方当事人名称 |
| **对方主体** | 对方当事人，下方灰色文字为对方律所 |
| **涉案金额** | 万元单位，超过 1000 万显示为"X千万"，超过 1 亿显示为"X亿" |
| **承办律师** | 头像+姓名显示 |
| **下一关键节点** | 日期+节点说明+距今天数，颜色反映紧迫程度 |
| **操作** | 鼠标悬停该行时出现，包含查看、编辑、更多 |

### 排序

点击以下列标题可切换升序/降序排列：

- 案件编号、案件名称、争议类型、案件阶段、涉案金额、立案日期、下一关键节点、最后更新时间

再次点击同一列标题可切换排序方向（↑升序 / ↓降序）。

### 操作按钮（鼠标悬停显示）

| 图标 | 功能 |
|------|------|
| 👁 眼睛 | 查看案件详情（右侧抽屉） |
| ✏️ 铅笔 | 编辑案件 |
| ⋯ 更多 | 展开菜单，包含"归档案件" |

## 4. 搜索与筛选

### 快速搜索

页面顶部的搜索框支持同时匹配以下字段的关键词：

- 案件编号、案件名称、案由
- 我方主体、对方主体
- 承办律师、对接业务部门
- 受理机构、当前进展

输入关键词后列表实时更新，无需按回车。右侧的 ✕ 按钮可清除搜索词。

### 高级筛选

点击搜索栏右侧的「高级筛选」按钮展开筛选面板，支持以下 11 个筛选维度同时组合使用：

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 案件编号 | 文本模糊匹配 | |
| 案件名称 | 文本模糊匹配 | |
| 案由 | 文本模糊匹配 | |
| 争议类型 | 下拉单选 | |
| 案件阶段 | 下拉单选 | |
| 承办律师 | 文本模糊匹配 | |
| 对接业务部门 | 文本模糊匹配 | |
| 我方主体 | 文本模糊匹配 | |
| 对方主体 | 文本模糊匹配 | |
| 立案日期区间 | 日期范围 | 起始日期和截止日期可单独填写 |
| 涉案金额区间 | 数字范围（万元）| 最小值和最大值可单独填写 |
| 显示已归档 | 开关 | 默认关闭，开启后归档案件也会显示 |

**活跃筛选数量**：「高级筛选」按钮上会显示当前生效的筛选条件数量（蓝色圆点数字）。

**清除所有筛选**：点击「清除筛选」按钮可一键重置所有筛选条件（快速搜索框也会清空）。

## 5. 查看案件详情

点击表格中任意一行，或点击操作栏中的👁图标，右侧会滑出**案件详情抽屉**。

### 详情抽屉内容结构

#### 顶部区域
- 案件名称、编号、受理机构
- 争议类型标签、案件阶段标签
- 紧急节点提示（红色/橙色警示条，仅在节点临近时显示）
- 操作按钮：编辑、归档、删除

#### 第一节：基本信息
案件编号、案由、受理机构、案件阶段、承办律师、对接部门

#### 第二节：当事人及金额
- 我方主体、对方主体、第三人/关联方
- 对方代理人、对方律所
- 三个金额卡片：涉案总金额（蓝色高亮）、我方主张、对方主张

#### 第三节：时间节点
- 六个关键日期逐行展示，截止类日期会根据临近程度显示颜色
- 底部蓝色/橙色/红色区块突出显示"下一关键节点"及距今天数

#### 第四节：当前情况
- 主要争议焦点
- 我方诉求/抗辩要点
- **当前进展**（黄色高亮背景，核心内容）
- 回款/执行进展
- 复盘要点
- 备注

#### 底部元数据
创建人、创建时间、最后更新时间

### 关闭详情抽屉
- 点击抽屉右上角的 ✕ 按钮
- 点击抽屉左侧的灰色遮罩区域
- 按键盘 `Escape` 键

## 6. 新增案件

点击页面右上角的「**+ 新增案件**」按钮，右侧弹出**表单抽屉**。

### 表单共四个分节

#### 第一节：基本信息（必填字段加 * 号）
- **案件编号***：建议统一命名规范，如 `SH2026-XXX`（地区缩写+年份+序号）
- **案件名称***：填写完整名称，建议格式"XX公司XX纠纷案"
- **案由***：填写法律案由，如"建设工程施工合同纠纷"
- 争议类型：从下拉菜单选择
- 受理机构：填写法院/仲裁委/监管机关全称
- **案件阶段**：从下拉菜单选择，新案件通常选"立案"
- 承办律师：填写主要负责人姓名
- 对接业务部门：填写内部部门名称

#### 第二节：当事人及金额
- **我方主体***：填写完整公司或个人名称
- **对方主体***：同上
- 第三人/关联方：多方时用顿号（、）分隔
- 对方代理人、对方律所：选填
- 三个金额字段：单位均为**万元**，支持小数

#### 第三节：时间节点
- 各日期字段均为选填，点击输入框可唤起日历组件
- **下一关键节点日期 + 说明**：建议每次更新案件时同步更新此字段，它直接影响列表中的紧迫度显示

#### 第四节：当前情况
- **当前进展***（必填）：记录最新动态，建议每次有进展时更新
- 其余字段选填，长文本请直接粘贴/输入，系统会自动保留换行格式

### 提交
- 点击底部「**创建案件**」按钮保存
- 点击「取消」或按 `Escape` 放弃并关闭

## 7. 编辑案件

有三种方式进入编辑：

1. 鼠标悬停到列表行 → 点击 ✏️ 图标
2. 打开案件详情抽屉 → 点击右上角「编辑」按钮
3. 编辑完成后点击底部「**保存修改**」按钮

> **注意**：表单不会自动保存草稿，请填写完毕后及时点击保存。

## 8. 归档与删除

### 归档

归档表示案件已不需要频繁查阅，但需要保留记录。

- 鼠标悬停列表行 → 点击 ⋯ → 「归档案件」
- 或在详情抽屉右上角点击归档图标

归档后：
- 案件默认从列表中隐藏
- 需在高级筛选中开启「显示已归档」才能看到
- 归档操作**可通过编辑案件撤销**（目前需手动修改 isArchived 字段，后续会增加界面按钮）

### 删除

在详情抽屉右上角点击 🗑️ 删除图标，确认后**永久删除**，无法恢复。

> **建议**：除非数据录入有误，否则请优先使用**归档**而非删除，以保留历史记录。

## 9. 字段说明

### 案件阶段枚举值

| 阶段 | 含义 | 典型使用场景 |
|------|------|------|
| 立案 | 已向法院/仲裁委提起申请，案件受理 | 刚提交起诉状 |
| 审理中 | 案件正在进行庭前准备、多次庭审 | 庭审尚未结束 |
| 一审 | 一审阶段（含庭审和等待判决） | 一审庭审完成，等待判决 |
| 二审 | 提起上诉后进入二审程序 | 对一审判决不服，上诉后 |
| 执行 | 已获得生效裁判文书，进入执行阶段 | 胜诉后申请执行、强制执行 |
| 结案 | 案件完全终结 | 履行完毕、调解达成、撤诉等 |

### 争议类型枚举值

| 类型 | 含义 |
|------|------|
| 合同纠纷 | 各类合同履行、违约、解除等纠纷 |
| 劳动争议 | 劳动合同、竞业限制、工伤赔偿等 |
| 知识产权 | 专利、著作权、商标、商业秘密等 |
| 侵权责任 | 名誉权、隐私权、产品侵权等 |
| 合规/行政 | 行政处罚、监管整改、合规调查等 |
| 其他 | 不属于以上类型的案件 |

### 金额字段规范

所有金额字段的单位均为**万元（人民币）**，填写时只填数字，无需填写单位。

| 字段 | 含义 |
|------|------|
| 涉案金额 | 案件涉及的总争议金额（双方标的合计） |
| 我方主张金额 | 我方在诉讼/仲裁中主张的赔偿/给付金额 |
| 对方主张金额 | 对方主张我方应支付的金额（仅在对方有反诉时填写）|

## 10. 颜色与状态标识说明

### 案件阶段颜色

| 阶段 | 颜色 |
|------|------|
| 立案 | 天蓝色 |
| 审理中 | 靛蓝色 |
| 一审 | 紫色 |
| 二审 | 琥珀色 |
| 执行 | 玫红色 |
| 结案 | 翠绿色 |

### 争议类型颜色

| 类型 | 颜色 |
|------|------|
| 合同纠纷 | 蓝色 |
| 劳动争议 | 橙色 |
| 知识产权 | 紫色 |
| 侵权责任 | 红色 |
| 合规/行政 | 青色 |
| 其他 | 灰色 |

### 节点紧迫度颜色（下一关键节点）

| 颜色 | 含义 | 时间范围 |
|------|------|---------|
| 🔴 深红 + 加粗 | 已逾期 | 日期已过 |
| 🔴 红色 | 极度紧急 | 3 天以内 |
| 🟠 橙色 | 紧急 | 4–7 天 |
| 🟡 琥珀色 | 需注意 | 8–14 天 |
| 灰色 | 正常 | 15 天以上 |

当节点处于**已逾期、极度紧急、紧急**状态时，详情抽屉顶部会显示橙色/红色警示横幅。

## 11. 常见问题

**Q：数据保存在哪里？**  
A：当前版本数据保存在浏览器内存中，**刷新页面后数据会重置**为系统内置的模拟数据。如需持久化保存，需要后端开发同学接入数据库（详见《后续开发指引》）。

**Q：多人同时使用时，数据会互相覆盖吗？**  
A：当前是纯前端版本，每位用户各自使用自己的浏览器实例，数据相互独立。如需真正的多人协作（数据共享、实时同步），需要接入后端 API，详见《后续开发指引》。

**Q：如何备份现有案件数据？**  
A：当前版本暂不支持导出，这是后续开发计划中的功能。临时方案是截图或手动复制"复制简报"（仅供参考）。后续版本将支持导出为 Excel。

**Q：搜索不区分大小写吗？**  
A：是的，所有文本搜索均不区分大小写。

**Q：金额筛选时，"最小值"和"最大值"可以只填一个吗？**  
A：可以。只填最小值表示"涉案金额 ≥ X 万元"，只填最大值表示"涉案金额 ≤ X 万元"。

**Q：案件编号有规范要求吗？**  
A：系统不强制约束格式，但建议团队内统一命名规则，例如：`地区缩写 + 年份 + 流水号`（如 `SH2026-001`），便于后续检索。

**Q："节点日历""数据统计""系统设置"页面什么时候上线？**  
A：当前版本这些功能标注为"即将上线"，属于后续开发计划。详情请参见《后续开发指引》中的功能路线图。
